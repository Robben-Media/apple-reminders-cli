# appre — Apple Reminders CLI

A Go CLI for Apple Reminders on macOS. Full CRUD, watch mode, and JSON-RPC 2.0 server.

## Installation

### Download Binary

Download the latest release from [GitHub Releases](https://github.com/Robben-Media/apple-reminders-cli/releases).

### Build from Source

```bash
git clone https://github.com/Robben-Media/apple-reminders-cli.git
cd apple-reminders-cli
make build
```
